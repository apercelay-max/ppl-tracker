Nous écrire

Un bug, une question, une demande sur tes données ? Ouvre un message sur notre page de suivi. N'y écris ni mot de passe ni information personnelle : on te répondra pour la suite.

Questions fréquentes

Comment supprimer mon compte ?

Dans l'appli : Réglages → Données & compte → Supprimer mon compte. Ton compte et tes données du cloud sont effacés définitivement. Les données de ton téléphone restent dessus.

Comment résilier PPL Pro ?

Sur ton iPhone : Réglages → ton nom → Abonnements → PPL Tracker → Annuler. Tu peux aussi appuyer sur « Gérer mon abonnement » dans l'écran PPL Pro. Fais-le au moins 24 h avant la fin de la période en cours.

J'ai changé de téléphone, où sont mes séances ?

Connecte-toi avec le même compte : tes séances se synchronisent. Sans compte, utilise Réglages → Données → Exporter sur l'ancien téléphone, puis Importer sur le nouveau.

Restaurer mon abonnement

Écran PPL Pro → « Restaurer mes achats », avec le même identifiant Apple que pour l'achat.

Parrainage

Le code se trouve dans Réglages → Données & compte → Parrainage. Il s'utilise dans les 7 jours qui suivent la création du compte du filleul.
